# RentMyRide 🚗

A car rental website built with **React** as a graduation project for the **Gaza Sky Geeks Frontend Development with React Training Program** in **June 2023**.

The project is a functional implementation inspired by the **Car Rent Website Design by Pickolab Studio**, with a focus on practicing modern frontend development, responsive UI design, and Firebase integration.

## 🎨 Design

The website was developed based on the following Figma design:

[Car Rent Website Design – Pickolab Studio](https://www.figma.com/design/zEr5CamoT2twTB3p2A9is7/Car-Rent-Website-Design---Pickolab-Studio--Community-?node-id=1-6)

## 🛠️ Technologies

* React
* JavaScript
* Material UI
* Firebase
* HTML & CSS

## 🔥 Backend

**Firebase** was used as the backend for the application, including database and storage functionality.

> **Note:** Some vehicle images may not load in the current version of the project because the original Firebase Storage setup is no longer available under the free tier. This has caused some loading issues when attempting to access details of cars.

## 🎓 Graduation Project

This project was completed in **June 2023** as part of the **Gaza Sky Geeks Frontend Development with React Training Program**.

## 🚀 Getting Started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/moath-dawood/RentMyRide.git
cd RentMyRide
npm install
npm start
```

The application will run locally at `http://localhost:3000`.
